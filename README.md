# NAVØR Barbearia
# Tema
Desenvolvimento de um site para uma barbearia que oferece serviços de cuidados pessoais e estética, além da comercialização de produtos e bebidas.

## Objetivos
Projeto desenvolvido em grupo com o objetivo de estruturar uma página para uma barbearia, visando à futura integração de um sistema ERP à plataforma.
