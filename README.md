# NAVØR Barbearia

> Seu estilo. Nossa precisão.

A **NAVØR** é um site institucional para uma barbearia fictícia que une corte, barba, estética e um lounge com bebida de cortesia. O projeto nasceu como trabalho em grupo da disciplina de Desenvolvimento Front-End e foi pensado para, no futuro, receber a integração com um sistema ERP.

🔗 **[Acesse o site](https://kauantoledo777.github.io/NAVOR_Barbearia/html/index.html)**

---

## O que tem no site

São 10 páginas, todas com o mesmo menu de navegação:

| Página | O que você encontra |
|---|---|
| **Início** | Apresentação da marca e atalhos para agendar ou conhecer a NAVØR |
| **Sobre Nós** | História, valores e diferenciais da barbearia |
| **Loja** | Pomadas, óleo de barba, shampoo, condicionador e kits |
| **Lounge** | O espaço de espera: sofás, leitura, Wi-Fi e bebidas |
| **Galeria** | Carrossel com fotos de cortes e do ambiente |
| **Contato** | Links para Instagram, WhatsApp, localização e agendamento |
| **Localização** | Mapa incorporado do Google Maps |
| **Depoimentos** | Avaliações de clientes |
| **Agendamento** | Formulário para escolher especialista, serviço, data e horário |
| **Equipe** | Os barbeiros e suas especialidades |
